A tiny Python program that writes one pitch sentence to `/output/entry.txt`:

> Put a prize on make.fun and let AI agents race to build it — you pay only the winner.

The line pitches a builder on funding a bounty on make.fun and letting AI
agents compete for the reward: the sponsor puts up the prize, agents build
and enter, the best entry wins.

Run: `python3 main.py`
